## Story

**As an agent, I want the inbox to keep up with me and my team, so that I never work from a stale view.**

## Acceptance criteria

1. New messages and teammate changes appear within 10 seconds without a manual refresh.
2. `j`/`k`/`Enter`/`e`/`a`/`⌘Enter` shortcuts work as specified, with a discoverable shortcut sheet.
3. `⌘K` opens a command palette for navigation, search, and conversation actions.
4. Polling pauses when the tab is hidden and resumes on focus.
5. Keyboard focus order matches visual order and all actions are reachable without a mouse.

---

## ⚠ `⌘Enter` must fire from inside the textarea

Front-End Spec §8 calls it **the most-pressed key in the product**. A naive `keydown` listener on the document never sees it, because the composer's textarea has focus and consumes the event.

This is the one shortcut whose failure is invisible in testing: every other key is pressed with the list focused, where a document handler works fine. **Test it with focus in the composer** — which is where it will always actually be used.

## AC4 is a cost control, not a nicety

Polling every 10 seconds, in every open tab, for every agent, all day, is the product's steady-state load. **Pausing on `visibilitychange` removes most of it** — an agent with the inbox in a background tab generates requests nobody will read.

§9.3 chose SWR polling over `LISTEN/NOTIFY` → SSE deliberately, and noted the upgrade path "if polling becomes a cost problem". This AC is the discipline that keeps that choice affordable.

## Tasks

### Task 1 — Polling (AC1, AC4)

- [ ] SWR against `/api/v1/conversations?since=` at 10s (§9.3). The **same cycle** feeds the sidebar counts Story 1.6 stubbed and Story 3.2 made real — one request, not three.
- [ ] Pause on hidden; resume and revalidate on focus.

### Task 2 — Shortcuts (AC2, AC5)

- [ ] `j`/`k`/`Enter`/`Esc`/`e`/`a`/`⌘Enter`/`⌘⇧Enter`/`r`/`⌘Z`/`/`/`?` per Front-End Spec §8.
- [ ] **No single-letter shortcut fires while a text input has focus.** `e` resolving a conversation while an agent types the word "email" is exactly the failure this prevents.
- [ ] `?` opens the shortcut sheet — AC2's "discoverable" half, and the only thing that makes the rest learnable.
- [ ] Focus order thread → draft → send (Front-End Spec §11), matching the task rather than the DOM's accident.

### Task 3 — Command palette (AC3)

- [ ] `⌘K` over Radix `command`, already installed by Story 1.6's Global row — no new budget spent.
- [ ] Navigation, conversation search, and actions on the current conversation.
